# Spotify Dataset Analysis 🎵

## Overview
This project analyzes a Spotify dataset to explore music trends, song popularity, artists, and audio features using Python and SQL.

## Objectives
- Analyze popular songs and artists
- Explore relationships between audio features and popularity
- Identify music trends
- Extract insights using SQL queries and data analysis

## Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL
- Jupyter Notebook

## Analysis Performed
- Data cleaning and preprocessing
- SQL-based data extraction and filtering
- Exploratory Data Analysis (EDA)
- Data visualization
- Popularity and audio feature analysis

## Conclusion
This project provides insights into Spotify music patterns by combining SQL queries and Python-based data analysis techniques.
